# 单晶铜热膨胀研究项目推进方案

**课题名称：**《单晶铜热膨胀行为及线膨胀系数的分子动力学研究》  
**小组成员：**【填写全体组员姓名】  
**实施周期：**7天

## 一、项目目标

通过Python调用LAMMPS，建立FCC单晶铜模型，采用Mishin 2001 EAM1势函数，在近零外压的NPT系综下研究300–800 K的热膨胀。

最终回答四个问题：

1. 晶格常数和体积如何随温度变化？
2. 300–800 K的平均线膨胀系数是多少？
3. 模拟结果是否稳定、可信？
4. 与实验参考数据相差多少，可能原因是什么？

**整体流程：**环境准备 → 建模 → 试跑 → 批量模拟 → 可靠性检查 → 数据分析 → Notebook论文 → PPT与视频。

## 二、文献调研后的方法选择

本项目定位为成熟方法的复现与精度验证。文献支持采用经验势分子动力学计算铜的热膨胀，现阶段保留原定的Mishin EAM1势，不增加合金、晶界、熔化或机器学习势训练。

- **主势依据：**Mishin等，2001，铜的结构稳定性与缺陷研究。
- **模型比较依据：**Lysogorskiy等，2021，比较Mishin EAM、ACE等模型的铜热膨胀。
- **流程参考：**Olsson等，2023，使用LAMMPS和Mishin势研究热膨胀；单晶和非晶模型每个温度平衡1 ns、采样1 ns。
- **实验对照：**优先整理Wang与Reeber的宽温区推荐数据，并核对Pojur与Yates的300–800 K实验工作。
- **统计依据：**采用独立重复和分块平均，不把相邻时间点当作独立样本。

完整21篇文献对比见同目录下的 `research_copper/allinone.md`。

## 四、建立模型

| 项目 | 初始设置 |
|---|---|
| 结构 | FCC单晶铜，不预设晶界和缺陷 |
| 原子数 | 10×10×10个常规晶胞，共4000个原子 |
| 晶体方向 | [100]、[010]、[001]分别沿盒子三个轴 |
| 边界 | 三维周期性边界 |
| 初始晶格常数 | 约3.615 Å，仅作建模初值 |
| 势函数 | Mishin 2001 EAM1，`Cu01.eam.alloy` |
| 调用方式 | `pair_style eam/alloy` |
| 单位制 | `metal` |

具体步骤：

1. 创建模拟盒子与铜原子。
2. 设置原子质量和势函数。
3. 对原子位置和盒子尺寸共同弛豫，减小初始应力。
4. 保存结构，用OVITO检查原子数、FCC排列和是否有重叠。

周期性边界代表晶体在各方向重复。本项目模拟的是体相单晶铜的近似模型，而不是有自由表面的铜纳米颗粒。

**完成标准：**4000个原子，结构正确，最小化正常结束，盒子尺寸合理。

## 五、编写代码并试跑

### 1. 代码分工

| 代码部分 | 负责内容 |
|---|---|
| LAMMPS输入模板 | 建模、势函数、温压控制、运行和数据输出 |
| Python运行程序 | 将温度和随机种子传入模板，批量调用LAMMPS |
| Python分析程序 | 读取数据，统计平均值，计算膨胀系数，绘图 |
| Notebook | 解释方法，组织图表，撰写论文 |

每条轨迹保存到独立文件夹，例如 `T300_seed1`，避免覆盖。记录软件版本、势文件、温度、种子、时间步和时长。

### 2. 先试跑两个温度

先计算300 K和800 K，确认建模、模拟、输出和分析整条流程可用。

| 参数 | 试跑设置 |
|---|---|
| 系综 | NPT，各向同性控压 |
| 目标外压 | 0 bar |
| 时间步长 | 1 fs，即`metal`单位下0.001 ps |
| 温控阻尼 | 从0.1 ps开始 |
| 压控阻尼 | 从1 ps开始 |
| 时长 | 平衡100 ps，再采样200 ps |

以上参数属于起始设置，需要通过实际结果检查。NPT本身包含时间积分，不对同一组原子再叠加NVE积分。

### 3. 检查试跑结果

- 是否报错、出现原子丢失或异常结构。
- 平均温度是否接近目标值。
- 体积和势能是否已围绕稳定平均值波动，而非持续漂移。
- 压力的长期平均是否合理；瞬时压力波动本身不代表失败。
- 输出数据能否被Python读取并正确绘图。

**完成标准：**两个温度均正常运行，可以得到温度、压力、体积随时间的曲线。

## 六、正式模拟与可靠性检查

### 1. 主计算

| 项目 | 计划 |
|---|---|
| 温度 | 300、400、500、600、700、800 K |
| 重复 | 每个温度3个不同初速度随机种子 |
| 数量 | 18条主轨迹，可靠性检查另计 |
| 起步时长 | 每条平衡200 ps、采样500 ps |
| 标量输出 | 每0.1 ps保存一次 |
| 结构输出 | 每5–10 ps保存一帧 |

每个温度分别恒温平衡和采样，不直接用连续升温过程计算平衡膨胀系数。只统计平衡后的数据。

输出字段：时间、温度、压力、势能、盒子三边长度、体积。保留原始标量轨迹，便于分块统计。

### 2. 可靠性检查

在300 K和800 K开展以下对照，每次只改变一个条件：

| 检查 | 对照设置 | 判断重点 |
|---|---|---|
| 时长 | 延长到平衡1 ns、采样1 ns | 平均值是否稳定，是否仍有漂移 |
| 尺寸 | 4000原子与6912原子 | 有限尺寸是否影响结果 |
| 时间步 | 1 fs与0.5 fs，物理时长相同 | 积分误差是否明显 |
| 重复性 | 比较3个种子 | 是否具有稳定的统计结果 |

重点比较晶格常数和300–800 K平均线膨胀系数。如果变化超过统计不确定性，应延长模拟或扩大模型，并更新相关主计算。不能只因运行正常就认定参数充分。

**完成标准：**能用数据说明最终采用的参数为何合理。尚未通过的检查应如实记录，不能写成“已收敛”。

## 七、数据分析

### 1. 晶格常数与体积

对于10×10×10的立方模型，晶格常数为：

$$
a(T)=\frac{\langle L_x(T)\rangle}{10}
$$

尖括号表示平衡后采样阶段的时间平均。体积同样取该阶段平均值。

### 2. 平均线膨胀系数

主结果采用以300 K为参考的工程温区平均定义：

$$
\bar{\alpha}_{300-800}
=\frac{a(800)-a(300)}{a(300)\times500}
$$

单位为K⁻¹。同时计算相对晶格膨胀：

$$
\varepsilon(T)=\frac{a(T)-a(300)}{a(300)}
$$

不要强求6个温度点做高阶拟合。瞬时系数与温区平均系数应分开标注。

### 3. 误差和实验比较

- 对轨迹做分块平均，检查均值误差是否随块长趋于稳定。
- 3次独立模拟分别求膨胀系数，再汇总均值和重复间标准差。
- 图表说明误差棒表示什么。
- 统一参考温度、温区、单位和定义后，再与实验比较。
- 区分实验测量值与文献推荐值，记录数据出处。
- 不能用室温单点系数代替300–800 K平均系数。

### 4. 必须形成的图表

1. 单晶铜模型图。
2. 代表性温度的平衡曲线。
3. 晶格常数随温度变化图，包含误差棒。
4. 相对体积随温度变化图。
5. 相对晶格膨胀的实验或文献对照图。
6. 参数、可靠性检查及平均膨胀系数汇总表。

晶格常数与体积在立方模型中相关，不能把两张图当成两项独立的精度验证。

## 八、Notebook论文写作

正文写在Markdown单元格中，分析和绘图放在代码单元格中。背景与方法从第一天开始写，结果、摘要和结论依据实际数据完成。

| 部分 | 需要写什么 |
|---|---|
| 题目与作者 | 课题名称、全部成员，按实际贡献确定作者顺序 |
| 摘要 | 目的、方法、主要数值结果和结论，最后写 |
| 简介 | 热膨胀的意义、已有研究、项目目标 |
| 计算方法 | 模型、势函数、参数、原始脚本、采样与统计方法 |
| 结果与讨论 | 平衡、可靠性、膨胀趋势、实验对照、偏差原因 |
| 结论 | 3–4条实际得到的结论 |
| 参考文献 | 势函数论文、对照研究、数据来源与软件论文 |

写作时区分三类问题：数值设置是否充分、统计误差有多大、势函数本身可能有何偏差。延长运行只能改善部分问题，不能自动消除模型偏差。

提交前检查：图号、坐标单位、引用、代码路径、配套数据是否齐全。保留模拟结果，使阅读和分析不必重新运行全部模拟。
