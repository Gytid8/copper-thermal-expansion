## 统计与表述审阅

- 正文明确使用三组重复系数的均值和同一组系数的t统计区间。它与旧汇总文件“先平均端点再求比值”的点估计仅相差约4.4×10⁻¹⁵ K⁻¹，低于本文报告精度；原始数据和原汇总文件均保留。
- 参数检查是端点、单组轨迹的实用敏感性检查，不被改写为全温区严格收敛或显著性检验。
- 残差图的MD误差来自各重复独立归一化后的分布，避免把共享300 K分母误当成独立误差；NIST不确定度没有被假定为零。
- 新图、表和正文只使用经完整性检查的24条轨迹。未运行的DFT、声子、电子结构和第二种势不写成本文结果。
